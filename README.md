# WebDesk

A hybrid portfolio that looks like a desktop, where projects are folders you can open.

Built with vanilla HTML, CSS and JavaScript, with no build step.

## Run it locally

Open `index.html` in a browser, or serve the folder:

```bash
npx serve .
# or
python3 -m http.server
```

## Structure

```
index.html      Landing page markup
css/style.css   Styles (light + dark mode)
js/main.js      Typewriter, draggable window, clock, icons
```
